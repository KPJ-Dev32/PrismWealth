# PrismWealth — Intelligent Portfolio & Wealth OS

> **A Product Management Showcase & Interactive Fintech MVP** built using React 18, TypeScript, Tailwind CSS, and Recharts on Bolt.new / Vite.

---

## 📌 Executive Summary & Problem Statement
90% of Indian retail investors over-diversify into 6+ mutual funds that hold the exact same 20 Nifty stocks, paying duplicate Total Expense Ratios (TER) for zero risk reduction. Furthermore, over 80% fail to harvest their annual **₹1.25 Lakh tax-free LTCG exemption** (Budget 2024 update).

**PrismWealth** solves these challenges with an intuitive, zero-jargon interface:
1. **Mutual Fund Overlap Detector**: Multi-select comparison of top Indian funds revealing shared stock concentration and fee drag.
2. **Smart Goal-SIP Allocator**: Compounding interest calculator with inflation adjustment and dynamic equity/debt/gold asset allocation.
3. **Budget 2024 LTCG Tax Harvester**: Interactive simulator showing real-time tax savings (12.5% LTCG saved) within the ₹1.25 Lakh zero-tax bracket.
4. **Market Crisis Stress-Tester**: Visualizing historical recoveries (2020 Covid, 2008 Lehman, 2022 Tech pullback) with behavioral nudges to curb panic selling.
5. **In-App PM PRD Drawer**: Embedded product requirements document detailing personas, user journeys, North Star metrics, and architectural trade-offs.

## 🛠️ Tech Stack & Architecture
- **Framework**: React 18 (Vite)
- **Language**: TypeScript
- **Styling**: Tailwind CSS (Dark/Light mode, Emerald Groww-style accents)
- **Icons**: Lucide React
- **Data Visualizations**: Recharts
- **Delight & Animations**: Canvas-Confetti

---

## 📊 Metrics & KPI Framework
- **North Star Metric**: Rebalanced AUM (Assets Under Management actively reallocated to target goals)
- **Secondary KPIs**:
  - Overlap Elimination Rate (>35% reduction in portfolio duplication)
  - D90 Goal-SIP Stickiness (>88% renewal rate)
  - Annual Tax Savings Generated (INR tax avoided legally via LTCG harvest)
- **Guardrail Metric**: Portfolio Turnover Rate (<15% to prevent over-trading and exit load fees)
